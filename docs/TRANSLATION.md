# Перевод и AI-редактирование

В «Настройки → Язык и исправления» выберите Yandex, DeepL или Google. Новые настройки используют Yandex; существующий выбор сохраняется. Переключатели исходящих и входящих сообщений работают независимо. Исходники остаются в истории. Для совместимости сохранён LibreTranslate, использующий тот же сервис.

Все обращения выполняются Node.js. Браузер и Electron обращаются только к `/api/translate`; автоматический перевод генерации использует тот же экземпляр `TranslationService` и кэш. Вкладки и мобильная версия имеют одинаковые настройки. Ключей переводчиков в интерфейсе нет.

## Настройка сервера

Скопируйте `.env.example` в `.env` в корне проекта. Для portable-приложения положите `.env` рядом с EXE; альтернативно задайте абсолютный `SAS_ENV_FILE`. Переменные окружения имеют приоритет. После изменения закройте все оболочки SAS, дождитесь завершения общего ядра (обычно до минуты) и запустите снова. `.env` не входит в экспорт данных и web-архив.

Yandex по умолчанию использует `https://translate.yandex.net/api/v1/tr.json/translate` с `ucid`, `srv=android`, `format=text`, `lang` и `text`. Google без ключа использует пакет `google-translate-api-x` (как SillyTavern) и batch-endpoint `https://translate.google.com/_/TranslateWebserverUi/data/batchexecute`. Старый single-endpoint доступен при `GOOGLE_TRANSLATE_MODE=web`; он чаще ограничивает запросы. Это публичные веб-endpoint'ы: их доступность зависит от провайдера; ошибки возвращаются в интерфейс без остановки SAS. Адрес можно заменить через `YANDEX_TRANSLATE_ENDPOINT` или `GOOGLE_TRANSLATE_ENDPOINT`, сохранив соответствующий формат протокола.

DeepL без пользовательского ключа подключается к собственному DeepLX-совместимому прокси, по умолчанию `http://127.0.0.1:1188/translate`. SAS не устанавливает этот сервис автоматически. Пример конфигурации:

```dotenv
DEEPL_TRANSLATE_ENDPOINT=http://127.0.0.1:1188/translate
DEEPL_TRANSLATE_MODE=deeplx
```

Прокси принимает `{ "text": "Hello", "source_lang": "auto", "target_lang": "RU" }` и возвращает `{ "code": 200, "data": "Привет" }`. Можно указать собственный удалённый адрес. Для прокси с авторизацией `DEEPL_API_KEY` передаётся как Bearer; явно оставьте режим `deeplx`.

Официальный DeepL API требует серверный ключ:

```dotenv
DEEPL_TRANSLATE_ENDPOINT=https://api-free.deepl.com/v2/translate
DEEPL_TRANSLATE_MODE=api
DEEPL_API_KEY=your-server-key
```

Для Pro замените endpoint на `https://api.deepl.com/v2/translate`. В режиме `api` также поддерживается совместимый прокси без ключа. Google Cloud включается через `GOOGLE_TRANSLATE_MODE=api`, `GOOGLE_API_KEY` и при необходимости `GOOGLE_TRANSLATE_ENDPOINT`. Секреты используют только серверные адаптеры. Устаревшие сеансовые ключи переводчиков нужно перенести в `.env`; ключи LLM, ComfyUI и LanguageTool продолжают работать как раньше.

## API и ограничения

```http
POST /api/translate
Content-Type: application/json
X-SAS-Client: web

{"text":"Hello","sourceLang":"en","targetLang":"ru","provider":"yandex"}
```

Ответ: `{ "translation": "Привет", "provider": "yandex", "text": "Привет" }`. Поле `text` и входные `source`/`target` временно сохранены для совместимости уже открытых клиентов. При fallback поле `provider` содержит фактически использованный сервис.

- Ошибки: 400 — неправильный запрос/язык, 429 — лимит, 502 — сбой внешнего сервиса, 500 — внутренняя ошибка. Ответ содержит `error`, `provider`, `code`, без сырого ответа внешнего сервиса.
- Максимум 100 000 UTF-16 единиц на текст; JSON ограничен 512 КБ. Пустой текст не отправляется. Части до 4 500 единиц, Google — до 1 000; приоритет границ предложений/абзацев, затем слов. Порядок и пробелы на границах сохраняются, пары суррогатов не разрываются.
- Кэш в памяти общего ядра: до 256 записей / 8 МБ, TTL 15 минут. Ключ учитывает провайдера, оба языка и полный текст. Ошибки не кэшируются. Кэш очищается при остановке.
- Сетевые ошибки, timeout и временные 5xx: до двух повторов через 500 и 1 500 мс. Авторизация, неподдерживаемый язык и 429 не повторяются. Одна попытка ограничена 12 секундами, весь перевод — 120 секундами.
- `settings.translation.translationFallback` по умолчанию `false`. При включении и недоступности основного сервиса проверяются Yandex → Google → DeepL с пропуском основного. Ошибки параметров и лимиты не вызывают переключения.
- Общее ядро принимает до 60 HTTP-запросов перевода в минуту, до 4 переводов одновременно и до 180 внешних попыток в минуту, включая автоматический перевод сообщений. Это общий бюджет всех оболочек: новый IP или окно не обходит лимит. Попадания в кэш не расходуют внешний бюджет.
- `TRANSLATION_DEBUG=true` включает метаданные: provider/source/target/status. Тексты, адреса с параметрами, ключи и заголовки не логируются.

Файлы реализации: `server/config/translation.js`, `server/providers/*.js`, `server/services/translationService.js`, `server/routes/translation.js`, `server/cache/translationCache.js`. Для нового сервиса добавьте адаптер `TranslationProvider.translate(text, sourceLang, targetLang, options)` и запись в реестр. Четвёртый необязательный аргумент передаёт сигнал отмены. При смене протокола меняется только серверный адаптер.

## AI-редактирование

«Улучшить текст» использует модель текущей истории, выбранную персону, карточку собеседника, сцену и последние сообщения. Короткий черновик разворачивается в игровой пост с жестами, интонацией и деталями намеченного действия. Модель получает инструкцию сохранять намерения игрока и не писать действия за собеседника. Результат зависит от выбранной модели.

Редактор показывает исходник, ожидание и предложенный вариант. Рассуждения `<think>` не попадают в черновик. Если модель повторяет исходник, выполняется одна повторная попытка; затем выводится ошибка, а не ложный успех. Текст вставляется только по кнопке и не отправляется в чат автоматически. Если исходный черновик успел измениться, автоматическая замена блокируется.

## Проверка

`npm test` проверяет адаптеры и их ошибки на контролируемых ответах, HTTP API, кэш, разбиение, retry/fallback, лимиты, AI-редактирование и существующие сценарии SAS. Тесты не требуют ключей и не отправляют истории внешним сервисам. Реальная доступность переводчиков проверяется кнопкой «Проверить» в настройках.

Источники протоколов: [SillyTavern translate.js](https://github.com/SillyTavern/SillyTavern/blob/release/src/endpoints/translate.js), [DeepL API](https://developers.deepl.com/api-reference/translate/request-translation), [Google-адаптер](https://github.com/AidanWelch/google-translate-api).
