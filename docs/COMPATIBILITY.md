# Совместимость SAS 0.3

SAS — отдельное приложение. Существующие JavaScript- и серверные Node.js-расширения SillyTavern без переноса не запускаются. Установка `manifest.json` не создаёт совместимость с `SillyTavern.getContext()`, DOM Таверны, jQuery, STscript и её внутренними модулями.

| Формат или инструмент | Реализовано | Ограничения |
| --- | --- | --- |
| Character Card JSON V1/V2 | Импорт основных полей, дополнительных блоков и неизвестных расширений; экспорт V2 | V3 переносит совместимое подмножество. Скрипты внутри карточек не выполняются. |
| Character Card PNG | Извлечение `chara` / `ccv3` из tEXt, zTXt и iTXt | Экспорт PNG не реализован. Портрет можно загрузить отдельно. |
| World Info / Character Book | JSON с массивом или объектом entries; ключевые слова, secondary keys с selective, постоянная активация, приоритет, регистр; экспорт | Рекурсия, sticky/cooldown/delay, probability, position и глубина внедрения сохраняются в исходных полях, но не исполняются. |
| Chat Completion preset | Включённые блоки и их порядок; базовые маркеры карточки/лора; temperature, top_p, max_tokens | Встроенные маркеры истории и весь движок шаблонов ST не воспроизводятся. Только макросы имён `{{char}}`, `{{user}}` и простые комментарии/trim. |
| Regex | JS RegExp, флаги, группы и замены; input/output, promptOnly/markdownOnly, min/maxDepth; изолированное исполнение с лимитом времени | Slash Commands, reasoning, STscript, исполняемые HTML-вставки не реализованы. Входной текст сохраняется без изменений. |
| RPG Companion · SAS | Поля сцены с обновлением по контексту, заметки, характеристики, d20 | Это встроенный аналог отдельных функций, не оригинальное расширение Marinara RPG Companion. |
| Озвучка SAS | Web Speech API, системные голоса | Наличие русских голосов зависит от Windows; внешние TTS-провайдеры не подключены. |
| SAS plugin JSON | Блок промпта и/или Regex-правила, включение/выключение | Нет JavaScript, файловых разрешений, сетевых вызовов или стороннего кода. |

## Собственный плагин

Импортируйте [пример плагина](../examples/narrator.sas.json) через «Расширения → Установить SAS-плагин», затем включите его. Плагин должен содержать `name`, `version` и хотя бы одно из `prompt` / `regexRules`. Формат — `sas-plugin-v1`.

```json
{
  "format": "sas-plugin-v1",
  "name": "Атмосфера",
  "version": "1.0.0",
  "description": "Детали окружающего мира",
  "prompt": "Добавляй конкретные звуки и запахи, когда это уместно."
}
```

Проверьте итоговую вставку кнопкой «Промпт» в чате. Плагины устанавливаются выключенными. Собственные Regex-правила плагина действуют при включении плагина; глобальные правила требуют включённого расширения «Regex-обработка».

## Пресеты Marinara

Импортируйте исходный Chat Completion preset JSON в «Промпты и пресеты». Выберите его активным и проверьте включённые блоки в инспекторе. У такого пресета может быть много макросов и условных конструкций SillyTavern; сложные конструкции нужно адаптировать вручную. Не заявляется полная эквивалентность конкретному оригинальному пресету.

SAS использует собственный минимальный безопасный вывод сообщений: обычный текст и курсив в `*звёздочках*`. HTML, CSS и JavaScript, полученные от модели, не исполняются.

## Память и мультиплеер

Память — редактируемые факты, отношения, эпизоды и дневник плюс создаваемая моделью сводка. Она добавляется в контекст; vector embeddings, автоматическое обнаружение противоречий и фоновое обновление Soul Memory пока не реализованы.

Мультиплеер — выбор сохранённой или новой истории с одной открытой комнатой и приглашением и собственным HTTP/WebSocket-сервером. Хост выбирает лор, задаёт очередность, редактирует сообщения, управляет правом гостей писать и создаёт изображения. Очередь автоматически переходит к следующему участнику, а генерацию хода ведущего запускает хост. Гости подключаются через SAS или браузер, бросают кубики и экспортируют чат; улучшение их текста выполняет их собственная модель. Комнаты через центральное облако не реализованы. Подробности — в [MULTIPLAYER.md](MULTIPLAYER.md).

В интерфейсе «Импорт данных» обозначает чтение совместимого файла, «Готовая функция» — встроенный инструмент SAS, «Плагин SAS» — собственный JSON-пакет с промптом или regex. Эти обозначения не обещают запуск оригинального JavaScript-расширения SillyTavern.
