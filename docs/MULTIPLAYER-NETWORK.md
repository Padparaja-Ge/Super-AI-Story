# Подключение к комнате без отдельного VPN

SAS предлагает два разных способа: поиск комнаты в имеющейся локальной сети и дополнительную интернет-ссылку через Cloudflare Quick Tunnel. Это не эмулятор Ethernet, не VPN-драйвер и не замена всем возможностям Radmin VPN.

## В одной сети

Хост по желанию включает обнаружение комнаты. Игрок нажимает поиск комнат, выбирает хоста и вводит код приглашения. Поиск использует UDP-порт 32123 и широковещательные адреса доступных IPv4-адаптеров. В объявление входят только название комнаты, режим, идентификатор и порт сервера комнаты. Код приглашения, ключ возвращения, чаты, персоны и адрес технического API не передаются.

Поиск выключен до явного включения. Ответы привязаны к случайному nonce запроса, ограничены размером и частотой. Отсутствие комнаты в результатах не доказывает её недоступность: некоторые Wi-Fi-сети запрещают соединения между клиентами, VPN может не пропускать broadcast, а брандмауэр — блокировать UDP. В таком случае можно вставить адрес приглашения вручную.

## Интернет-ссылка

1. Откройте комнату и настройте лобби/допуск.
2. Явно установите дополнительный сетевой компонент cloudflared кнопкой в SAS. Это отдельный исполняемый файл до 100 МБ, не LLM-модель.
3. Нажмите запуск интернет-ссылки. SAS направляет туннель **только на localhost-порт сервера комнаты**, а не на основной API с моделями и настройками.
4. Передайте участникам HTTPS-приглашение и допускайте их через лобби.
5. Остановите ссылку после игры. При закрытии комнаты, смене комнаты или завершении SAS принадлежащий ему процесс туннеля останавливается.

Компонент загружается только из официального релиза `cloudflare/cloudflared` на GitHub. Размер и SHA256 проверяются по полю `digest` GitHub Releases API. Если контрольная сумма недоступна или не совпадает, файл не устанавливается. Перед запуском проверяются путь, размер и SHA256 установленного файла. Запускается только экземпляр, установленный SAS; программы из PATH или произвольного пользовательского пути не исполняются. Автозапуска, установки службы, изменения брандмауэра и автоматического скачивания нет.

Quick Tunnel предоставляет временный публичный адрес `*.trycloudflare.com`. Это внешний сервис Cloudflare, через который проходит трафик комнаты. Адрес может меняться при каждом запуске, доступность зависит от сервиса и сети. Настройки допуска SAS продолжают действовать. Данный механизм публикует веб-комнату, но сам по себе не ретранслирует WebRTC-голос: при строгом NAT для голоса может дополнительно потребоваться TURN.

Источники: [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/), [описание поля digest в GitHub Releases API](https://docs.github.com/en/rest/releases/releases), [код команды cloudflared](https://github.com/cloudflare/cloudflared/blob/master/cmd/cloudflared/tunnel/cmd.go).

## Если соединения нет

Диагностика проверяет доступность `/room-info` за ограниченное время и ожидает ответ SAS. Она не отправляет код приглашения и не проверяет пароль, права допуска или качество маршрута для голоса. Если комната недоступна, проверьте IP нужного Ethernet/Wi-Fi/VPN-адаптера, порт и брандмауэр. Для разных сетей альтернативой остаётся [Radmin VPN](https://www.radmin-vpn.com/): установите его у участников, объединитесь в одну сеть и используйте IP соответствующего адаптера.

Тесты установки/старта туннеля выполняются с подставными загрузками и процессами. Публичный туннель не открывается автоматическими тестами; реальную доступность внешнего сервиса необходимо проверить в своей сети по явному запуску пользователем.
