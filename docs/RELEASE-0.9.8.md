# SAS 0.9.8

Обновление локальной генерации текста и настроек моделей.

- Проверка совместимости шаблона диалога для Gemma: приложение подсказывает, когда нужно использовать шаблон из GGUF.
- В настройках видны работающий шаблон и изменения для следующего запуска модели.
- Кнопка восстановления штатного шаблона и сэмплеров, отдельный профиль rpDungeon Gemma 4 E4B Luchador Q8_0.
- Применение готового профиля заменяет весь набор сэмплеров, включая ранее включённые дополнительные фильтры.
- Улучшена обработка служебных маркеров моделей и остановка зацикленных ответов в историях, фанфиках и комнатах.
- Доработано формирование описаний для иллюстраций по сцене.

## Установка

Скачайте **SAS-Windows-0.9.8.zip**, распакуйте в отдельную папку и запустите **SAS.exe**. Для веб-режима откройте **Start-SAS-Web.cmd** из этого же архива. Папки `app/` и `engines/` должны оставаться рядом с EXE.

Небольшой **SAS-Start-0.9.8.zip** устанавливает полный пакет через `Start-SAS.cmd`. Готовая Windows-поставка не требует Node.js и сборки исходников. Модели текста, embeddings и ComfyUI подключаются отдельно.

Перед обновлением сохраните текущую работу и закройте SAS и его веб-сервер. Устанавливайте выпуск в отдельную папку. Истории и настройки находятся в `%APPDATA%\Super AI Story\data`; скачанные модели — в выбранном вами каталоге.

Если ранее вручную выбирался неподходящий шаблон, откройте **Модели и API → Локальные модели**, нажмите **«Восстановить шаблон и сэмплеры»**, затем остановите и снова запустите модель. Изменение настроек не исправляет уже сохранённый ошибочный ответ — его нужно перегенерировать или отредактировать.
