# Инициатива и озвучка · SAS 0.8.9

## Очерёдность D&D / НРИ

Инициатива = основной модификатор Ловкости − штрафы экипированных предметов.
Модификатор считается как `floor((очки − 10) / 2)`: 14 очков дают +2, 8 дают −1.

| Вес | Штраф к инициативе |
| --- | --- |
| Лёгкий | 0 |
| Средний | 0,5 |
| Тяжёлый | 1 |

Штраф каждого надетого предмета брони считается отдельно. Вес оружия задаётся
в инвентаре. Оружие учитывается при экипировке; предметы в сумке не влияют.
Например: Ловкость 14, три средних доспеха и тяжёлая секира:
`2 − 0,5 − 0,5 − 0,5 − 1 = −0,5`.

В бою игроки и NPC входят в общую очередь по убыванию инициативы. Когда очередь
доходит до группы с равными значениями, движок автоматически бросает каждому
`1д20 + инициатива`. При одинаковых результатах перебрасывают только оставшиеся
равные участники. Броски видны в журнале. В новом раунде равенства разрешаются
заново. Отрицательные значения и половины сохраняются.

Очередь фиксируется на начало раунда. Переэкипировка меняет следующий раунд,
чтобы смена предметов не давала второй ход. Мёртвые и отключившиеся участники
пропускаются; новые участники боя вступают в следующем раунде. Изменение
экипировки по-прежнему расходует быстрое действие в бою.

В «Мой ход» видны инициатива, её расчёт и раскрываемая очередь. Чат и игровые
действия доступны своему участнику в его ход. Хост действует за NPC только в
очередь этого NPC. AI отыгрывает последовательных NPC до следующего игрока,
описывает результат и передаёт ход. Если ответ оборвался, «Дописать» продолжает
повествование без повторного выполнения атак и без сброса очереди.

Вне боя очередь включает игроков, затем мастер описывает последствия.
Обычный Role Play сохраняет прежнюю очередность комнаты.

Новые NPC получают Ловкость по типу: воин 10, лучник/зверь 14, маг 12,
лекарь 8. Хост может выбрать NPC в «Мой ход → Управлять участником» и
открыть его лист из инвентаря между боями: изменить характеристики,
добавить доспехи и настроить вес оружия. Старые NPC сохраняют свои значения.

## Начать озвучивание

Откройте «Расширения → Голоса персонажа → Настроить голоса», включите кнопки у сообщений и выберите голос.
Нажмите значок динамика рядом с ответом AI в РП, мультиплеере или эпизодом Фанфика.
Повторное нажатие останавливает чтение. Одновременно воспроизводится один текст.

Длинный пост делится на предложения. Пока звучит текущее, готовится одно
следующее. Слишком длинное предложение делится по словам. Вся книга сразу
в аудио не превращается. Настройки фиксируются на время чтения; память,
история и текст сообщения при этом не редактируются. Фанфик и комнаты
не получают чужую память из-за озвучивания.

CPU выбран по умолчанию. Для Kokoro в Windows GPU использует DirectML;
для XTTS/Fish — CUDA. На AMD можно использовать DirectML для Kokoro, а
для XTTS/Fish в этой поставке — CPU. CPU использует компактные Q8-веса Kokoro,
GPU — FP32: Q8 с DirectML оказался нестабилен при реальном тесте.

## Модели и место на диске

| Пакет | Веса | Установка |
| --- | --- | --- |
| Kokoro RU · Света, Маша, Дима | 929 МБ | Включён в поставку |
| Kokoro-82M · мужские и женские голоса | 425 МБ | Включён в поставку |
| Silero v3_1_ru · 5 готовых русских голосов | 61,9 МБ | Включён в поставку |
| Silero v3_en · en_0–en_117 | 57,2 МБ | Включён в поставку |
| Silero v4_ru | 40,1 МБ | По кнопке |
| XTTS v2 | 1 876 МБ | По кнопке |
| Fish Speech 1.5 | 1 466 МБ | По кнопке |

Размеры десятичные и включают файлы голосов и обе версии весов Kokoro.
Каждый пакет весов меньше 2 ГБ. Python, PyTorch и CUDA-библиотеки устанавливаются
отдельно и могут занимать ещё несколько ГБ. Fish 1.5 выбран потому, что его
инференс-пакет укладывается в лимит; большие поколения Fish автоматически не скачиваются.

На этом компьютере задана «Папка загрузки с Hugging Face»: `D:\Models`.
Озвучка находится в `sas-tts\models`, изолированные движки — в
`sas-tts\runtime`. ComfyUI и его Python-окружение не меняются.
На новом компьютере используется папка HF, выбранная в «Модели и API».
При первом открытии озвучки включённые в поставку Kokoro копируются туда
без интернета. Подключённые модели продолжают находиться по прежним путям
после смены папки загрузки.

Наведение на модель показывает вес и грубую оценку времени для выбранного
CPU/GPU. После настоящей генерации появляется измеренный RTF: отношение
времени подготовки к длине аудио. Холодный запуск медленнее следующей фразы;
оценка не является гарантией скорости.

## Silero: готовые русские и английские голоса

В «Расширения → Голоса персонажа → Настроить голоса» выберите **Silero TTS**.
Для русского уже доступны `kseniya`, `aidar`, `baya`, `xenia`, `eugene`;
для английского — голоса `en_0`–`en_117`. Есть автоматический выбор языка
по фразе или явный выбор русского/английского. В смешанных фразах автоопределение
ориентируется на наличие кириллицы; для полностью английского чтения выберите English.

RU `v3_1_ru` и EN `v3_en` включены в Windows-сборку и веб-архив. При первом
открытии раздела веса и CPU-движок копируются в выбранную папку загрузки HF:
`sas-tts/models/silero` и `sas-tts/runtime/silero-cpu`. Интернет и установленный
системный Python для этой Windows x64 поставки не требуются. Смена папки HF
подготавливает Silero в новой папке; старые файлы не удаляются. Открытие настроек
впервые может занять время из-за копирования движка.

Веса двух моделей занимают вместе 119,1 МБ. Сам автономный CPU-движок Python,
PyTorch и NumPy дополнительно занимает около **452 МБ** без сжатия.
Предустановленный Windows-движок предназначен для Windows x64. При установке
веб-сервера на другую ОС понадобится совместимое Python-окружение, которое
создаётся кнопкой установки движка; Windows-библиотеки там не используются.

Частота выбирается между 8/24/48 кГц; по умолчанию 24 кГц. Для русского можно
включить автоматические ударения и восстановление «ё». Настраиваются потоки CPU,
пауза, громкость и выгрузка по простою. Голоса назначаются персонажам, одному
ведущему D&D/НРИ и рассказчику фанфика. Клонирования у Silero нет.

Модель остаётся загруженной между фразами и голосами одного языка. При смене
модели прежние веса освобождаются. Предложения готовятся последовательно с
подготовкой следующего во время воспроизведения текущего. Вес проверяется по
SHA-256 перед использованием; альтернативная v4 RU устанавливается отдельно
из проверяемого каталога с резервным источником загрузки. Это список совместимых
пакетов SAS, произвольные исполняемые `.pt` в него не импортируются.

CPU выбран по умолчанию. GPU-вариант Silero использует CUDA и требует отдельной
установки зависимостей; на AMD используйте CPU. CUDA в проверке 0.8.9 не тестировалась.
На Ryzen 9 7900X с четырьмя потоками короткие фразы после прогрева занимали примерно
0,18–0,64 секунды, первая — около 4 секунд. Это измерения конкретного компьютера,
качество произношения по каждому слову независимым распознавателем не оценивалось.

Silero получает только текст выбранного сообщения. Настройки, профили голосов,
аудио, фонетические замены и служебные данные чтения не добавляются в промпт LLM,
лорбуки или память.

## XTTS, Fish и свои голоса

Нажмите «Скачать и установить» для нужной модели. Установка создаёт отдельный
движок для выбранного CPU/CUDA; сменив устройство, установите его вариант
кнопкой «Установить движок CPU/CUDA». Если подходящего Python нет в Windows,
SAS подготовит собственный portable Python. Прогресс можно отменить.

В разделе клонирования выберите готовый мужской/женский голос или добавьте
чистую запись WAV, MP3, M4A/AAC, FLAC, OGG/Opus, WebM, AIFF или WMA длиной 3–30 секунд, до 16 МБ, и её точную расшифровку.
XTTS имеет встроенные мужской/женский голоса. Для XTTS и Fish при установке
загружаются два небольших синтетических образца Piper/HiFi-Captain (мужской/женский).
У них английская расшифровка; обе модели могут произносить русский текст
с их тембром. Собственные записи сохраняются по имени и доступны обоим движкам.
В «Назначение голосов» выберите голоса персонажей, один голос мастера D&D/НРИ
и голос рассказчика фанфика. Образы и модель повторно не загружаются для каждой фразы.

Параметры XTTS: темп, temperature, top-k/top-p, штраф повторов и длины,
длина conditioning-образца, его части и нормализация. Fish: temperature,
top-p, штраф повторов, предел аудиотокенов, размер внутреннего блока и seed.
Общие параметры: громкость, пауза, длина фразы, потоки CPU и выгрузка после простоя.
Начните с значений по умолчанию и меняйте по одному параметру.

«Сторонняя модель / сервер» поддерживает папки в формате Kokoro ONNX,
Kokoro RU, XTTS v2 или Fish 1.5. Для произвольной другой архитектуры
используйте её OpenAI-совместимый сервер с `/v1/audio/speech`, возвращающий WAV.
GGUF чат-модели в этот раздел не подходят. Подключение папки сохраняет
оригинальные файлы; универсальные параметры — голос, темп и ресурсные ограничения.
Для собственной папки XTTS/Fish есть «Установить только движок»:
стандартные веса повторно не скачиваются.

## Проверка и ограничения

На Ryzen 9 7900X пять русских/английских голосов подготовили тестовые фразы
за 3,1–4,7 секунды; длина аудио — 4,8–5,5 секунды. DirectML на этом компьютере
прошёл реальную проверку пяти голосов: прогретые Маша и Adam — около
0,9 и 0,4 секунды, холодные переключения — 2–4 секунды. Эти результаты
относятся к данным фразам и этому компьютеру.

В 0.8.7 реально проверены установка XTTS/Fish на CPU, русская озвучка обоих
готовых голосов, клонирование импортированного MP3 и двух пресетов.
XTTS: холодная фраза ~23–25 с, следующие ~9–11 с для 3–6 с аудио.
Fish: ~33–51 с для 4–6 с аудио на Ryzen 9 7900X, 4 потока.
CUDA для этих двух движков в этом прогоне не проверялась.
Kokoro RU использует встроенную расстановку ударений eSpeak; сложные имена
и неоднозначные русские слова могут звучать неточно. Японский G2P для Kokoro
в этой поставке не подключён. Доступные языки отображаются по движку.

Лицензии компонентов и моделей: `server/third-party/SPEECH-NOTICES.md`.

При ошибке установки откройте «Журнал установки» в карточке движка.
Журнал хранится в `sas-tts/runtime/<движок>-<устройство>/install.log`; последнее
состояние сохраняется после перезапуска SAS. Уже скачанные исправные веса
проверяются по SHA-256 и не скачиваются повторно. Декодер входит в отдельное
окружение Python; системный FFmpeg также подходит (`SAS_TTS_FFMPEG` — свой путь).

В Kokoro RU исправлены потерянная твёрдая «л», нормализация ё/аффрикат,
редукция гласных и длина «щ». Неизвестные фонемы теперь вызывают понятную ошибку
вместо молчаливого удаления. Для сложных имён есть «Произношение имён и терминов»:
это меняет только озвучку, сообщения и память остаются прежними.
