# Языки интерфейса

SAS поддерживает русский, английский, японский, упрощённый китайский и корейский интерфейс. Выбор находится в **Настройки → Язык и исправления → Язык интерфейса**. Он также доступен в приветствии и на первом шаге обучения.

Переключение происходит без перезагрузки страницы. Язык сохраняется отдельно от историй и их автосохранения. В настольном приложении выбор сохраняется при перезапуске, даже если изменился локальный порт. Гостевая веб-комната имеет собственный переключатель и сохраняет выбор в браузере.

Все переводы включены в приложение и работают без интернета. Загружается только словарь выбранного языка. Никакие сервисы перевода или дополнительные модели для этого не используются.

Язык интерфейса не меняет содержимое карточек, имена, сообщения, сохранения, системные промпты, язык генерации и настройки перевода диалогов. Пользовательские тексты остаются в исходном виде. Подробные диагностические журналы сторонних движков также сохраняют оригинальные сообщения.

## Поддержка переводов

- Каталоги: `shared/locales/en.json`, `ja.json`, `zh-CN.json`, `ko.json`.
- Русский исходный текст служит ключом. Динамические значения передаются отдельно: `t('Эпизод {0}', [number])`.
- Подстановки `{0}`, `{1}` нужно сохранять во всех переводах. Они вставляются как текст, без HTML.
- `node scripts/interface-catalog.mjs` обновляет перечень строк, не отправляя данные наружу.
- `node --test tests/interface-language.test.mjs` проверяет полноту словарей, параметры и сохранение предпочтения.
- `node scripts/run-ui-languages.mjs` проверяет собранный интерфейс в изолированном Electron с временными данными. Перед ним выполните `npm run build`.

Исходные данные и значения `input`/`option` не переводятся. Новые строки интерфейса следует оборачивать в `t`, а не переводить весь DOM или загружаемые документы.
