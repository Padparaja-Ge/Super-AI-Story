# Сторонние компоненты

Уведомление SAS не изменяет лицензии сторонних компонентов. Их лицензии сохраняются внутри готового приложения и его среды выполнения.

- Electron / Chromium / Node.js, React, Express, ONNX Runtime и другие зависимости распространяются с собственными уведомлениями.
- llama.cpp — MIT; включённые CUDA-библиотеки — на условиях NVIDIA CUDA EULA.
- Kokoro-82M — Apache-2.0; Kokoro RU — OpenRAIL (см. карточку установленной модели).
- Silero `v3_1_ru` / `v3_en` — **CC BY-NC-SA 4.0**, включая ограничение некоммерческого использования. Это условие модели, оно не означает передачу прав на SAS.
- Независимая утилита фонем `phonemes.mjs` и eSpeak — **GPL-3.0-or-later**. Она общается с движком через отдельный процесс. Соответствующий исходный код и инструкции сборки находятся в **SAS-eSpeak-source-0.9.2.zip** на странице этого выпуска. Эти исходники публикуются для соблюдения GPL, а не являются исходниками SAS целиком.
- Python — PSF, PyTorch и NumPy — BSD; лицензии сохранены в среде озвучки.
- Необязательные XTTS v2, Fish Speech, сторонние модели и голоса имеют отдельные условия, которые доступны при их установке.

Полное уведомление о компонентах озвучки: встроенный `server/third-party/SPEECH-NOTICES.md`. Соответствующие лицензии не ограничиваются условиями `COPYRIGHT.md`.
