# SAS · Super AI Story

Локальная русскоязычная платформа для историй и ролевых игр с ИИ. Обычный RP, Фанфик, мультиплеер RP/D&D/НРИ, персонажи, лорбуки, память, локальные GGUF и API, ComfyUI и озвучка.

**Это публичный репозиторий готовых выпусков. Исходники и история разработки хранятся отдельно.**

## Установка и запуск · Windows 10/11 x64

1. На странице [последнего выпуска](https://github.com/Padparaja-Ge/Super-AI-Story/releases/latest) скачайте **SAS-Start-0.9.2.zip**.
2. Распакуйте в свою папку, например `D:\SAS`. Не запускайте из архива или `Program Files`.
3. Запустите **Start-SAS.cmd**. Он скачает готовый **SAS.exe** этого выпуска в ту же папку, проверит SHA-256 и откроет программу. Node.js, npm и компиляция не нужны.

Для установки без сети заранее скачайте **SAS.exe** из того же выпуска и положите рядом с `Start-SAS.cmd`. Для дальнейшего запуска можно использовать сам EXE. Офлайн работают уже установленные локальные модели; облачные API, переводчики и загрузки требуют подключения. LLM и необязательные тяжёлые модели автоматически не скачиваются.

Первая распаковка EXE может занять время. Не запускайте несколько копий установщика. Требуется около 8 ГБ свободного места с учётом распаковки, без LLM. Бинарник пока не подписан сертификатом издателя; проверьте источник загрузки и SHA-256, если Windows покажет предупреждение.

## Веб-режим

- **Start-SAS-Web.cmd** — самостоятельный веб-сервер без окна настольного приложения.
- **Start-SAS-Web-Shell.cmd** — только веб-оболочка; использует ядро уже работающего SAS с той же папкой данных.
- **Stop-SAS-Web.cmd** — штатно останавливает веб-сервер из этой папки. Настольное приложение продолжает работать.

Адрес по умолчанию: `http://127.0.0.1:3212`. Файл **web-server.json** можно редактировать до запуска. Для доступа из LAN/VPN укажите `host: "0.0.0.0"`, разрешённые IP/подсети в `allowlist` и свой `accessKey`. Пустой ключ разрешает вход без ключа, но IP-списки продолжают действовать. VPN установщик не отключает. Через интернет без настройки маршрутизации доступ не гарантируется. Этот выпуск содержит сервер для Windows; Linux-сборка в него не входит.

Десктоп и веб используют одно ядро и одну папку данных. При обновлении сначала закройте старый SAS и его веб-сервер, подождите 30 секунд, затем запускайте новую версию.

## Данные, обновление и восстановление

- Истории, настройки и ключи: `%APPDATA%\Super AI Story\data`. Модели — в выбранной пользователем папке.
- Журнал запуска веб-сервера: `%APPDATA%\Super AI Story\web-runtime`. Логи приложения доступны в его диагностике.
- **Repair-SAS.cmd** проверяет EXE и скачивает его заново, если файл повреждён. Персональные данные, модели и `web-server.json` не перезаписываются.
- Для обновления распакуйте маленький стартовый ZIP нового выпуска в новую папку; перенесите свой `web-server.json`. Данные в AppData останутся прежними. Перед обновлением рекомендуется резервная копия из SAS.
- Для удаления закройте SAS и удалите папку установки. AppData и скачанные модели сохраняются, пока вы не удалите их сами.
