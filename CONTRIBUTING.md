# Участие в разработке

Исправления, улучшения интерфейса, тесты, документация и расширения приветствуются. Для большого изменения сначала опишите задачу в Issues, чтобы согласовать совместимость и объём работ.

## Подготовка

1. Создайте fork и отдельную ветку.
2. Выполните `npm ci`, затем `npm test` и `npm run build`.
3. Внесите изменение и добавьте проверку, если меняется поведение.
4. Опишите в pull request проблему, результат, способ проверки и ограничения.

Не включайте `node_modules`, `data`, `.env`, загруженные модели, результаты сборки, логи и персональные истории. Новые зависимости добавляйте вместе с изменением lock-файла и проверкой их лицензий.

## Архитектурные правила

- Внешние сервисы и секреты обслуживаются backend; ключи не передаются в клиентский код.
- Память и контекст изолируются по истории, произведению и комнате. Расширение не должно неявно объединять их.
- Расчёты D&D/НРИ выполняет игровой движок; модель получает проверенные результаты.
- Длительные операции должны поддерживать отмену и не блокировать Node.js.
- Изменение формата данных требует обратной совместимости либо явной миграции и теста.

## Расширения

Для отдельной функции сначала рассмотрите плагин: [SAS API 2](docs/EXTENSIONS-API.md). Рабочий пример находится в `examples/sas-extensions/campaign-notes`. Авторы самостоятельных расширений выбирают свою лицензию и отвечают за входящие зависимости и материалы. Если в расширение копируется код SAS, сохраняются условия Apache-2.0 и соответствующие уведомления.

Проверяйте активацию, отключение и обновление: ресурсы, обработчики, таймеры и соединения должны освобождаться. Привязывайте работу с контекстом к явно выбранным режимам. Указывайте доступ к сети и файлам в описании расширения.

## Права на вклад

Отправляя оригинальный вклад для включения в SAS, вы предоставляете его по Apache-2.0, если заранее явно не согласованы другие условия. Авторские права на ваш самостоятельный вклад сохраняются за вами. Не отправляйте код и материалы, на распространение которых у вас нет необходимых прав.
